# Used Car Price Prediction

## Project Overview
This project predicts the selling price of a used car using machine learning. It includes a web application built with Python that allows users to enter car details and receive a predicted price.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Machine Learning
- Streamlit (if used in the application)

## Project Files
- `app.py` — Web application code
- `used_car_price_model.pkl` — Saved machine learning model

## How to Run
1. Install the required Python libraries.
2. Ensure both project files are in the same folder.
3. Run the application using the appropriate command for your framework.

## Project Goal
To estimate used car prices based on vehicle information using a trained machine learning model.
